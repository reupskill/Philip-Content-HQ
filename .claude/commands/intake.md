Process new intake material from Dr. Philip Babalola: $ARGUMENTS

This is how the knowledge base grows. The intake questionnaire structure (Core Thought → POV → Founder Experience → Realtor Insight → Investor Insight → Market Observation → Leadership → Sales & Trust → Philosophy → Content Angle → Hooks → Closing Reflection → Raw Notes) is the expected input shape, but process whatever form the material arrives in.

Process:
1. Read the new material fully.
2. Extract and file, updating each knowledge-base file — merge, never overwrite existing entries:
   - New facts/milestones → `01-founder-profile.md` and `07-market-data-facts.md`
   - New or evolved positions → `03-core-beliefs-pov.md` (note if a POV changed)
   - New stories → `04-stories-bank.md` with themes
   - New verbatim phrases → `05-signature-phrases.md`
   - New audience insight → `06-audience-personas.md`
   - New hooks → `hooks-bank.md`
3. Flag any contradiction with existing knowledge-base content for the user to resolve — do not silently pick a side.
4. Summarize: what was added where, plus the 3–5 strongest new content angles the material unlocks.
